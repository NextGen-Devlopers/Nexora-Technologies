# Nexora Technologies

**Innovating Today. Engineering Tomorrow.**

Nexora Technologies is a modern technology company website developed to showcase innovative digital solutions, including software development, web design, cybersecurity, IT consulting, and digital transformation.

This project is built with React and Vite as a collaborative group project using GitHub for version control and teamwork.

## 🚀 Features

- Responsive and modern user interface
- Home page with company highlights and featured services
- About Us page presenting the company's mission, vision, and values
- Services page showcasing technology solutions
- Projects page displaying portfolio projects
- Our Team page introducing team members
- Contact page with a contact form interface
- Client-side navigation using React Router
- Reusable React components
- Responsive layouts for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- **React** — User interface development
- **Vite** — Development server and build tool
- **React Router DOM** — Page navigation
- **CSS3** — Styling and responsive design
- **JavaScript ** — Website functionality
- **GitHub** — Version control and collaboration

## 👥 Team Collaboration

This project is developed collaboratively by a six-member team using a GitHub Organization.

Team members contribute through separate branches, pull requests, code reviews, and coordinated integration of website pages and shared components.

## 🎨 Design Direction

The website follows a modern technology-company aesthetic, featuring:

- Midnight navy backgrounds
- Electric blue and cyan accents
- Clean typography
- Modern cards and layouts
- Responsive navigation
- Consistent spacing and reusable styles
